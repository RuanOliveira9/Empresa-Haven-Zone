## 📌 Visão Geral do Projeto

O Haven Zone é uma aplicação web voltada para a experiência do usuário (*UX/UI*) no segmento de moda e bem-estar. O projeto tem como objetivo principal conectar o consumidor ao seu estilo de vestuário ideal, priorizando a ergonomia visual, a identidade estética e o conforto no dia a dia.

Desenvolvido como projeto prático do curso Técnico em Informática, este ecossistema web explora conceitos fundamentais do desenvolvimento front-end e da arquitetura de informação, garantindo navegabilidade intuitiva, alta performance e semântica de código.

---

## 💻 Tecnologias e Ferramentas Utilizadas

O projeto foi construído utilizando tecnologias nativas do desenvolvimento web para assegurar um código limpo, modular e de alta manutenibilidade:

- **HTML5 Semântico:** Estruturação robusta da interface, aplicação de boas práticas de acessibilidade (*WAI-ARIA*) e otimização para mecanismos de busca (*SEO*).
- **CSS3 Avançado:**
  - **Arquitetura e Estilização:** Organização de estilos modulares com variáveis CSS (*Custom Properties*).
  - **Layout Engine:** Utilização de Flexbox e CSS Grid Layout para estruturação responsiva e alinhamento preciso de elementos.
  - **Animações e Interatividade:** Transições suaves (*transitions/animations*) para aprimorar a usabilidade do usuário sem comprometimento da taxa de quadros (FPS).
- **Git & GitHub:** Controle de versionamento do código-fonte e documentação técnica.

---

## 🎨 Principais Funcionalidades

- [x] **Home / Landing Page:** Apresentação da marca Haven Zone, proposta de valor e destaque de coleções baseadas no equilíbrio entre estilo e conforto.
- [x] **Guia de Estilo Personalizado:** Seção interativa voltada para a descoberta da identidade visual e preferências de ajuste (*fit*) do usuário.
- [x] **Catálogo Interativo:** Exibição de peças de vestuário categorizadas por nível de conforto e ocasião.
- [x] **Interface Responsiva:** Adaptação contínua da interface para dispositivos móveis (*Mobile First*), tablets e desktops via Media Queries.
- [x] **Design System Interno:** Padronização de tipografia, paleta de cores neutras/acolhedoras e componentes reutilizáveis.
